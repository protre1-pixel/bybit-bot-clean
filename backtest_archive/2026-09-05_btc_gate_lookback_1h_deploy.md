# 2026-09-05 배포: BTC 모멘텀 게이트 lookback 4시간 → 1시간 축소

## 배경

같은 날 앞서 배포한 BTC 모멘텀 게이트(`2026-09-05_btc_momentum_gate_deploy.md`, lookback
4시간/16캔들)를 실거래 반영한 뒤, 사용자가 "1시간봉이나 12시간·일봉으로 하면 결과가
달라지냐"는 lookback 민감도에 대한 궁금증을 제기. 이를 계기로 4코인·1년 기준 1시간/4시간
(현재라이브)/12시간/24시간 4개 lookback을 스윕 검증했고, lookback이 짧을수록 승률·PF·MDD·
수익 전 지표가 일관되게 개선되는 경향을 확인. 다만 1시간 결과가 게이트 열림 4.5%(연
16.5일)뿐이라 4코인 378건 표본으로는 우연일 가능성이 있다는 우려가 있어, 사용자 요청으로
bot1 실거래 15종 전체 × 1년으로 표본을 늘려 1시간과 4시간(현재라이브)을 동일 조건
직접 재검증. 사용자가 결과를 확인한 뒤 1시간으로 전환 결정.

## 정의

- BTC 등락률 = 직전 N시간 종가 대비 현재 종가 등락률 (15분봉 데이터만 사용, N시간 =
  15분봉 N*4개 전 종가와 비교하는 롤링 방식 - 별도로 "N시간봉"을 조회하는 게 아님)
- `|등락률| >= 1.0%`면 그 시각엔 전체 코인(BTC 포함) 롱/숏 무관 신규 진입 허용, 아니면
  전부 차단 (방향 연동 안 함, 기존 게이트 정의와 동일 - 이번 변경은 N값만 16 → 4로 축소)

## 변경 내용

`app/services/price_service.py`: `BTC_GATE_LOOKBACK` 상수를 `16`(4시간) → `4`(1시간)로
변경. `is_btc_momentum_gate_open()` 독스트링/로그 메시지의 "4시간" 표기를 "1시간"으로
수정, 관련 주석 블록에 이번 lookback 축소의 배경과 검증 결과를 기록. 게이트 판정
로직(캔들 조회, 캐싱, 폴백) 자체는 변경 없음.

`app/services/trading_service.py`: `auto_trade()` 내 게이트 체크 블록의 주석/로그
메시지를 "BTC 4h 등락률"→"BTC 1h 등락률"로 갱신. 게이트 호출 로직(`is_btc_momentum_gate_open()`
결과에 따라 `signal = None`) 자체는 변경 없음 - 실제 lookback 값은 `price_service.py`에서만
관리.
